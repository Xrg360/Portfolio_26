## Outline

- One trace per turn; child spans for each model call and tool call.
- Recording token and cost usage as span attributes.
- Audit spans for destructive actions.
- Example span tree:

```text
turn
├─ model.call
├─ tool.call  read_logs
└─ audit      action recorded
```
